# 📊 Derivable Judgement: A Statistical Decision-Making Model

### Turning Public Health Data into Statistical Insights

**Derivable Judgement** is a Python-based inferential statistics project that explores patterns in public health data using statistical methods. It applies hypothesis testing, confidence intervals, and relationship analysis to understand health-related variables and support data-driven decision-making.

## 🎯 Project Objectives

* Understand and apply inferential statistics.
* Calculate 95% confidence intervals for age and BMI.
* Compare glucose levels between smokers and non-smokers.
* Compare diabetes proportions across smoking groups.
* Investigate associations between smoking status and diabetes.
* Compare glucose levels across different age groups.
* Analyze covariance and correlation between age and BMI.
* Interpret p-values and statistical test results.

## 🗂️ Dataset Overview

The project uses a public health dataset containing demographic and health-related information.

| Variable         | Description          |
| ---------------- | -------------------- |
| `age`            | Age of an individual |
| `age_group`      | Age category         |
| `bmi`            | Body Mass Index      |
| `smoking_status` | Smoking status       |
| `glucose_level`  | Blood glucose level  |
| `diabetes`       | Diabetes indicator   |

The dataset is analyzed using Python to explore patterns, compare groups, and examine relationships between variables.

## 🧪 Statistical Methods Implemented

### 1. Confidence Interval

Calculates 95% confidence intervals for the mean age and BMI.

### 2. Independent Samples T-Test

Compares glucose levels between smokers and non-smokers.

### 3. Two-Proportion Z-Test

Examines differences in diabetes proportions between smoking groups.

### 4. Chi-Square Test of Independence

Investigates the association between smoking status and diabetes.

### 5. One-Way ANOVA

Compares average glucose levels across different age groups.

### 6. Covariance Analysis

Measures how age and BMI vary together.

### 7. Correlation Analysis

Examines the strength and direction of the relationship between age and BMI.

## 📈 Project Workflow

1. **Data Collection:** Load the public health dataset.
2. **Data Inspection:** Examine data types, dimensions, and missing values.
3. **Statistical Estimation:** Calculate descriptive statistics and confidence intervals.
4. **Hypothesis Testing:** Apply appropriate statistical tests.
5. **Result Interpretation:** Evaluate p-values at a significance level of 0.05.
6. **Decision-Making:** Draw conclusions based on the statistical evidence.
